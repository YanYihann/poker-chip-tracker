# App demo

[Looping GIF](pokerchip-ledger-demo.gif) · [Full-resolution video](pokerchip-ledger-demo.mp4)

Recorded on October 15, 2026 from the current application at source revision `c8ad685`, in English at a 1100 × 820 viewport.

The walkthrough shows the lobby, three-player Beginner quick matching, room preparation and readiness, a server-dealt hand played through all streets, automatic settlement, and detailed hand results. Alex, Maya, and Chen are demo accounts in an isolated local PostgreSQL database. Cards and payouts come from the actual game server. The clip trims waiting time and appends a scroll through the same hand's results.

The GIF is scaled to 900 pixels wide for the README; the MP4 preserves the original resolution. These replace the retired `online-table-demo.gif` recording.
